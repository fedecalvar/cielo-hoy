# Cielo Hoy ☁️

App del tiempo construida con React + Vite y Tailwind CSS, usando la API gratuita de Open-Meteo.

## Funcionalidades

- Buscar el clima de cualquier ciudad del mundo
- Ver temperatura actual, mínima y máxima
- Estado del cielo, humedad y viento
- Ciudades sugeridas al cargar la página
- Dark mode / Light mode

## Stack

- React + Vite
- Tailwind CSS
- Open-Meteo API (gratuita, sin API key)
